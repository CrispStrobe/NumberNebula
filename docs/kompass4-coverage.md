# KOMPASS 4 mathematics coverage

This is the coverage of content package `numbernebula_kompass_math` version
`2.0.0`, schema 2. The 32 identifiers come from the project-owned `kompass4`
competency matrix. They are not official IBBW item or proficiency codes.

The package contains 128 original bilingual tasks: 64 practice, 32 independent
checks and 32 rehearsal items. Each competency has two practice families and
one held-out family in each independent mode. The four domains contain 48
numbers/operations, 32 geometry, 28 measurement and 20 data/chance tasks.

Existing-game links are enrichment opportunities. Their normal free-play scores
do not supply KOMPASS competence evidence. Four additional interactive labs live
inside the optional course; the global registry still contains its existing
48 games. The source asset distinguishes competencies represented in published
2025 material from curriculum supplements; neither label claims future test
weighting or an official blueprint.

## New interactive labs

| Lab | Interactions |
| --- | --- |
| Number dock / Zahlendock | Build a number with place values, exchange bundles while preserving value, locate a number-line midpoint. |
| Supply station / Versorgungsstation | Calculate purchases and construct change, advance a clock, combine capacities, convert length. |
| Data observatory / Datenobservatorium | Build a chart, adjust a bag to equal chances, classify events and explore draws. |
| Geometry workshop / Geometriewerkstatt | Select reflection axes, complete a cube net, reconstruct a side view from a building. |

Each lab has three stages of help, repeatable seeded rounds, a saved draft and
keyboard/tap controls. Completion remains practice evidence. The first response,
partial first points, later successful response, hints and active work time are
kept separately.
